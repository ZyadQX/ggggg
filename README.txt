نسخة Frontend كاملة لتجربة نظام العب الآن حتى نهاية الدور وبداية الدور التالي.
تشمل إنشاء/دخول الغرف، كود، انتظار الخصم، بدء المباراة، اختيار الصورة، الشات،
الأسئلة، الإجابات، Guess، إشعارات التخمين، المؤقت، الفوز، وبداية دور جديد.

هذه نسخة Prototype محلية وليست Online حقيقية بين جهازين بعد.
عند ربط Supabase Realtime لاحقًا يمكن تحويل نفس الواجهات إلى Multiplayer حقيقي.
